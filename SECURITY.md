# Security Policy for DEADRYX

DEADRYX is an offline-first Progressive Web Application. User data is stored locally in the browser's `localStorage` and `IndexedDB`. When enabled, cloud backups are synchronized exclusively to the user's private Google Drive `appDataFolder`.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.1.x   | :x:                |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of our athletes and gym-goers seriously. If you discover a potential security vulnerability (e.g. Cross-Site Scripting, Content Security Policy bypass, or insecure storage handling), please report it responsibly:

1. **Email**: Send vulnerability reports directly to **[bharatjid021@gmail.com](mailto:bharatjid021@gmail.com)**.
2. **Details to include**:
   - Description of the vulnerability and potential impact.
   - Exact steps or proof-of-concept to reproduce the issue.
   - Affected browser, operating system, and screen resolution.
3. **Response timeline**:
   - Initial response: within 48 hours.
   - Assessment and triage: within 5 business days.
   - Fix release: depending on severity, typically within 7 business days.

Please do not open public GitHub issues for sensitive security vulnerabilities.
